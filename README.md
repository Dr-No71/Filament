# Filament Manager für Windows

## Windows-EXE bauen
Das Projekt enthält einen GitHub-Actions-Workflow unter `.github/workflows/windows-exe.yml`.

1. Lege ein neues GitHub-Repository an.
2. Lade den kompletten Inhalt dieses Ordners hoch.
3. Öffne auf GitHub den Bereich **Actions**.
4. Starte den Workflow **Windows EXE bauen**.
5. Nach erfolgreichem Lauf findest du unter den Workflow-Artefakten `FilamentManager-Windows`.
6. Das ZIP enthält `FilamentManager.exe`.

Python muss auf deinem PC **nicht** installiert sein. Der Build wird von GitHub auf Windows durchgeführt.
